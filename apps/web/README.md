# Fannout web

Next.js App Router app for Fannout. See [`DESIGN.md`](./DESIGN.md) for the
design rules and [`CLAUDE.md`](./CLAUDE.md) for the project layout.

```sh
pnpm dev          # http://localhost:3000
pnpm lint         # ESLint + design-rule lint
pnpm test         # brand tokens, counters, lint rules
pnpm contrast     # WCAG contrast of every token pair
```
